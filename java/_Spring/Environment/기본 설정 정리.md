# 기본 설정 정리

## 1. 환경 변수 설정

 - 노출이 가능한 항목은 profile별 설정 사용
    - application.yml, application-local.yml, application-dev.yml, application-prod.yml
 - 보안이 필요한 설정은 OS 환경 변수 혹은 Command Line Arguments 사용
```yml
# application.yml
server:
  port: ${SERVER_PORT:8080}
  
spring:
  datasource:
    url: ${DATABASE_URL:jdbc:h2:mem:testdb}
    username: ${DATABASE_USERNAME:sa}
    password: ${DATABASE_PASSWORD:}
    
app:
  jwt:
    secret: ${JWT_SECRET:default-secret}
    expiration: ${JWT_EXPIRATION:3600000}

# # 운영환경에서 환경변수 설정
# export DATABASE_URL=jdbc:mysql://prod-db:3306/myapp
# export DATABASE_USERNAME=prod_user
# export DATABASE_PASSWORD=secure_password
# export JWT_SECRET=super-secure-jwt-secret
```

## 환경 변수 사용

 - @ConfigurationPropertiesScan
 - @ConstructorBinding, @ConfigurationProperties
```java
// 현재 패키지부터 스캔
@ConfigurationPropertiesScan
@Configuration
public class PropertiesConfig {}

// 환경 변수 주입
@Getter
@ConstructorBinding
@ConfigurationProperties(prefix = "app")
public class AppProperties {
    private final String name;
    private final String version;
    private final int timeout;
    private final Security security;
    
    public AppProperties(String name, String version, int timeout, Security security) {
        this.name = name;
        this.version = version;
        this.timeout = timeout;
        this.security = security;
    }
    
    @Getter
    public static class Security {
        private final String jwtSecret;
        private final long jwtExpiration;
        
        public Security(String jwtSecret, long jwtExpiration) {
            this.jwtSecret = jwtSecret;
            this.jwtExpiration = jwtExpiration;
        }
    }
}
```
<br/>

 - @Value
```java
@Component
public class ValueExampleService {
    
    @Value("${server.port}")
    private int serverPort;
    
    @Value("${app.name}")
    private String appName;
    
    // 기본값 설정
    @Value("${app.timeout:30}")
    private int timeout;
    
    // 문자열 기본값
    @Value("${app.description:Default Description}")
    private String description;
}
```
