# 외부 환경 변수 설정

## 환경 변수 우선 순위

 - devtools 활성 상태일 때 $HOME/.config/spring-boot 디렉토리 내 devtools 전역 설정
 - @TestPropertySource
 - @SpringBootTest 속성(properties)
 - Command Line Arguments
 - SPRING_APPLICATION_JSON(환경 변수 또는 시스템 변수에 포함된 인라인 JSON)
 - ServletConfig 초기화를 위한 매개변수
 - ServletContext 초기화를 위한 매개변수
 - JNDI attributes(java:comp/env)
 - 자바 시스템 변수(System.getProperties())
 - OS 환경 변수
 - application.properties 파일
    - classpath 내부에 존재하면서 .config 디렉토리에 위치한 application.properties
    - classpath 내부에 존재하면서 .config 디렉토리에 위치한 application-{profile}.properties
    - classpath 내부에 존재하는 application.properties
    - classpath 내부에 존재하는 application-{profile}.properties
    - classpath 외부에 존재하면서 config 디렉토리에 위치한 application.properties
    - classpath 외부에 존재하면서 config 디렉토리에 위치한 application-{profile}.properties
    - classpath 외부에 존재하는 application.properties
    - classpath 외부에 존재하는 application-{profile}.properties
 - @Configuration 클래스
 - 기본 속성(SpringApplication.setDefaultProperties)

## 환경 변수 주입 방법

 - `devtools 전역 설정 (활성 상태일 때)`
    - 파일 위치: $HOME/.config/spring-boot/devtools.properties
    - devtools의 동작(리로드 제외·포함 경로 등)을 제어하는 전용 설정이야. 일반 app.name 같은 앱 프로퍼티를 넣는 용도는 아님.
```yml
# $HOME/.config/spring-boot/application.properties
server.port=8081
logging.level.root=DEBUG
```
<br/>

 - `@TestPropertySource`
    - 사용처: 테스트 클래스 위에서 테스트 전용 프로퍼티 주입
```java
@TestPropertySource(properties = {
    "test.property=test-value",
    "server.port=9999"
})
@SpringBootTest
class MyTest {
    @Value("${test.property}")
    private String testProperty;
}

// 또는 파일로
@TestPropertySource(locations = "classpath:test.properties")
@SpringBootTest
class MyTest {
}
```
<br/>

 - `@SpringBootTest 속성(properties)`
```java
@SpringBootTest(properties = {
    "spring.profiles.active=test",
    "custom.value=springboot-test"
})
class ApplicationTest {
}
```
<br/>

 - `Command Line Arguments`
```bash
java -jar app.jar --app.name=via-cli --server.port=8081 --spring.profiles.active=prod
```
<br/>

 - `SPRING_APPLICATION_JSON (환경변수/시스템변수의 인라인 JSON)`
```bash
# 환경 변수로
export SPRING_APPLICATION_JSON='{"server":{"port":8080},"logging":{"level":{"root":"INFO"}}}'

# 시스템 프로퍼티로
java -Dspring.application.json='{"server":{"port":8080}}' -jar myapp.jar
```
<br/>

 - `ServletConfig 초기화 파라미터`
    - 설정: 임의 서블릿 등록 시 init param 부여 → 프로퍼티 소스로 노출
```java
@Bean
ServletRegistrationBean<HttpServlet> sampleServlet() {
    ServletRegistrationBean<HttpServlet> reg =
        new ServletRegistrationBean<>(new HttpServlet(){}, "/sample");
    reg.addInitParameter("app.name", "via-servlet-config");
    return reg;
}

@Configuration
public class WebConfig implements WebApplicationInitializer {
    @Override
    public void onStartup(ServletContext servletContext) {
        DispatcherServlet servlet = new DispatcherServlet();
        ServletRegistration.Dynamic registration = 
            servletContext.addServlet("dispatcher", servlet);
        registration.setInitParameter("contextConfigLocation", "/WEB-INF/spring-config.xml");
    }
}
```
<br/>

 - `ServletContext 초기화 파라미터`
    - 설정: 서블릿 컨텍스트에 init param 부여
```
// Java 방식
@Bean
ServletContextInitializer servletContextInitializer() {
    return ctx -> ctx.setInitParameter("app.name", "via-servlet-context");
}

// XML 방식
<!-- web.xml -->
<web-app>
    <context-param>
        <param-name>contextConfigLocation</param-name>
        <param-value>classpath:applicationContext.xml</param-value>
    </context-param>
</web-app>
```
<br/>

 - `JNDI attributes (java:comp/env)`
    - Tomcat 예: context.xml
```xml
<Context>
  <Environment name="app.name" value="via-jndi" type="java.lang.String"/>
</Context>
```
<br/>

 - `자바 시스템 변수`
```bash
# JVM 옵션으로 설정
java -Dapp.name=via-system-prop -jar app.jar

# Java 코드에서 적용
# System.setProperty("custom.system.property", "system-value");
```
<br/>

 - `OS 환경 변수`
    - 스프링이 직접 환경 변수를 프로퍼티로 노출(대문자/언더스코어 → 소문자/닷 표기)하므로 @Value("${app.name}") 가 APP_NAME 를 읽을 수 있게 app.name 키를 매핑해두면 됨
```bash
export APP_NAME=via-env

# application.properties에서 매핑: app.name=${APP_NAME}
java -jar app.jar
```
<br/>

 - `application.properties`
```
1. src/main/resources/.config/application.properties
2. src/main/resources/.config/application-dev.properties
3. src/main/resources/application.properties
4. src/main/resources/application-dev.properties
5. ./config/application.properties (실행 디렉토리 기준)
6. ./config/application-dev.properties
7. ./application.properties
8. ./application-dev.properties
```
<br/>

 - `@Configuration 클래스 (@PropertySource)`
    - 사용처: 임의의 파일을 프로퍼티 소스로 추가
```java
@Configuration
@PropertySource("classpath:custom.properties")
public class PropertyConfig {
    
    @Bean
    @ConfigurationProperties(prefix = "app")
    public AppProperties appProperties() {
        return new AppProperties();
    }
}

@Component
@ConfigurationProperties(prefix = "database")
public class DatabaseProperties {
    private String url;
    private String username;
    private String password;
    
    // getters and setters
}
```
<br/>

 - `기본 속성 (SpringApplication.setDefaultProperties)`
    - 사용처: 최하위 우선순위의 기본값 제공(어디에서도 안 주면 이 값 사용)
```java
@SpringBootApplication
public class App {
  public static void main(String[] args) {
    SpringApplication app = new SpringApplication(App.class);

    Map<String, Object> defaults = new HashMap<>();
    defaults.put("app.name", "via-defaults");
    defaults.put("server.port", "8080");
    app.setDefaultProperties(defaults);

    app.run(args);
  }
}
```
