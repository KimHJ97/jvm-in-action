 - 기본/고급 디버깅 기법
 - 로그를 효과적으로 활용하여 앱 동작 파악하기

 - 프로파일링을 이용하여 실행 코드를 찾기
 - 프로파일링으로 앱이 데이터를 저장하는 로직 이해
 - 앱 간의 상호 통신 방식 분석
 - 시스템 이벤트 모니터링
