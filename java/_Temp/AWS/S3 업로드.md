# AWS S3 파일 업로드

## 1. AWS 관련 작업

### 1-1. 버킷 만들기

 - 객체 소유권: ACL 비활성화
 - 퍼블릭 액세스 차단 설정: 체크 해제

객체 소유권 ACL 정책이 활성화되어 있으면, 객체 업로드시 객체는 업로드하는 계정의 소유가 되어 다른 계정에서 접근이 불가능하다. 따라서, 다른 계정에서 접근하게 하기 위해서는 객체 업로드시 ACL을 적용하거나 버킷에 객체 소유권 ACL 정책을 비활성화한다.

### 1-2. 사용자 만들기

 - 사용자 이름: file-manager
 - 권한 옵션: 직접 정책 연결
 - 권한 정책: AmazonS3FullAccess

IAM > 액세스 관리 > 사용자 화면에서 사용자를 추가한다.

### 1-3. 액세스 키 만들기

 - 사용 사례: AWS 외부에서 실행되는 애플리케이션

IAM > 엑세스 관리자 > 사용자 > 생성한 사용자 이름 클릭 > 보안 자격 증명 화면에서 액세스 키를 만든다.

## 2. 코드 작업

 - `build.gradle`
```groovy
dependencies {
    implementation 'org.springframework.cloud:spring-cloud-starter-aws:2.2.6.RELEASE'
}
```

 - `application.yml`
```yml
cloud:
  aws:
    region: ap-northeast-2
    credentials:
      access-key: ${AWS_S3_ACCESS_KEY}
      secret-key: ${AWS_S3_SECRET_KEY}
    s3:
      bucket-name: your-bucket-name
```

 - `AwsProperties`
```java
@Getter
@Setter
@Configuration
@ConfigurationProperties(prefix = "cloud.aws")
public class AwsProperties {
	private Credentials credentials;
	private S3 s3;
	private String region;

	@Getter
	@Setter
	public static class Credentials {
		private String accessKey;
		private String secretKey;
	}

	@Getter
	@Setter
	public static class S3 {
		private String bucketName;
	}
}
```

 - `S3Config`
```java
@RequiredArgsConstructor
@Configuration
public class S3Config {

	private final AwsProperties awsProperties;

	@Bean
	public AmazonS3 amazonS3() {
		BasicAWSCredentials credentials = new BasicAWSCredentials(
			awsProperties.getCredentials().getAccessKey(),
			awsProperties.getCredentials().getSecretKey()
		);

		return AmazonS3ClientBuilder.standard()
			.withRegion(awsProperties.getRegion())
			.withCredentials(new AWSStaticCredentialsProvider(credentials))
			.build();
	}
}
```

 - `FileInfoDto`

 - `FileManager 인터페이스`

```java
public interface FileManager {
	FileInfoDto uploadFile(MultipartFile file);
	List<FileInfoDto> uploadFiles(List<MultipartFile> files);
}
```

 - `S3FileManager`
    - FileManager 구현체
    - AWS S3에 파일을 관리하는 기능을 제공
```java
@Slf4j
@RequiredArgsConstructor
@Component
public class S3FileManager implements FileManager {

	private final AmazonS3 amazonS3;
	private final AwsProperties awsProperties;

	@Override
	public FileInfoDto uploadFile(MultipartFile file) {
		// 파일 기본 정보
		String bucketName = awsProperties.getS3().getBucketName();
		String originalFileName = file.getOriginalFilename();
		long fileSize = file.getSize();
		String contentType = file.getContentType();

		// 저장 경로, 파일명
		String savedFileName = UUID.randomUUID() + "_" + originalFileName;
		String folderPath = createYearMonthPath();
		String fullFilePath = folderPath + savedFileName;

		try {
			ObjectMetadata metadata = new ObjectMetadata();
			metadata.setContentLength(fileSize);
			metadata.setContentType(contentType);

			// S3에 파일 업로드
			amazonS3.putObject(bucketName, fullFilePath, file.getInputStream(), metadata);

			// S3 URL 생성
			String fileUrl = amazonS3.getUrl(bucketName, fullFilePath).toString();

			return FileInfoDto.builder()
				.fileName(originalFileName)
				.contentType(contentType)
				.size(fileSize)
				.path(fileUrl.replace("/" + savedFileName, ""))
				.savedFileName(savedFileName)
				.build();

		} catch (IOException e) {
			throw new CommonException(FileErrorCode.FAILED_SAVE_FILE);
		}
	}

	@Override
	public List<FileInfoDto> uploadFiles(List<MultipartFile> files) {
		return files.stream()
            .map(this::uploadFile)
            .collect(Collectors.toList());
	}

	private String createYearMonthPath() {
		LocalDate now = LocalDate.now();
		return now.format(DateTimeFormatter.ofPattern("yyyy/MM")) + "/";
	}
}
```
